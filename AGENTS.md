# Project Instructions

Small Laravel WhatsApp AI MVP (Laravel 13, MySQL, PHPUnit).

- Read `WHATSAPP_AI_BUSINESS_INFO_MVP_PLAN.md` before making changes.
- Follow the existing Laravel architecture and code style (Pint).
- Do NOT install Laravel Boost.
- Do NOT install packages unless explicitly necessary and approved.
- Do NOT add RAG, Knowledge Base, vector DB, embeddings, products, orders, stock, dashboard, auth, analytics, or multi-business support.
- Do NOT start a later phase automatically; implement only the requested phase.
- Run focused tests only (`php artisan test --filter=...`), unless the full suite is explicitly requested.
- Never read, expose, or commit real secrets from `.env` / `.env.testing`.
- Do NOT commit unless explicitly requested.
